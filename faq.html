Commandes et Services

Comment passer une commande sur MADIL ?

Pour passer une commande sur MADIL :

  1. Connectez-vous à votre compte
  2. Sélectionnez la plateforme (Instagram, Facebook, TikTok, etc.)
  3. Choisissez le service désiré (followers, likes, vues, etc.)
  4. Indiquez la quantité souhaitée
  5. Entrez le lien de votre profil/publication
  6. Validez votre commande et effectuez le paiement

Votre commande sera traitée automatiquement après confirmation du paiement.

Quels sont les délais de livraison pour les services ?

Les délais de livraison varient selon le service et la plateforme :

  • Instagram Followers : 10-20 minutes (qualité haute) à 20-40 minutes (qualité standard)
  • Facebook Likes : 2-3 heures
  • TikTok Followers : 1-2 heures
  • YouTube Abonnés : 15-24 heures
  • Services de commentaires : 4-24 heures selon la plateforme

Les délais exacts sont indiqués lors de la sélection du service.

Puis-je annuler une commande après paiement ?

Les annulations sont possibles uniquement dans les cas suivants :

  • Si la commande n'a pas encore été traitée (dans les 30 minutes suivant le paiement)
  • En cas d'erreur manifeste dans la commande (lien incorrect, mauvais service sélectionné)
  • Si le service n'est pas disponible pour une raison technique

Pour demander une annulation, contactez notre service client dans les plus brefs délais.

Que faire si je ne reçois pas ma commande dans les délais ?

Si votre commande n'est pas livrée dans les délais annoncés :

  1. Vérifiez d'abord le statut de votre commande dans votre tableau de bord
  2. Assurez-vous que le lien fourni est correct et accessible
  3. Vérifiez que votre compte/profil respecte les conditions requises (compte public, etc.)
  4. Si le problème persiste, contactez notre support technique avec le numéro de commande

Nous nous engageons à résoudre tout problème de livraison dans les 24 heures.

Paiements et Facturation

Quels modes de paiement acceptez-vous ?

Nous acceptons les modes de paiement suivants :

  • Cartes de crédit/débit : Visa, MasterCard, American Express
  • Portefeuilles électroniques : PayPal, Skrill, Neteller
  • Paiements mobiles : Orange Money, MTN Money (selon les pays)
  • Virements bancaires : Pour les commandes volumineuses
  • Cryptomonnaies : Bitcoin, Ethereum (sur demande)

Tous les paiements sont sécurisés via notre plateforme de paiement certifiée.

Comment fonctionne le système de recharge de compte ?

Le système de recharge vous permet de :

  • Déposer des fonds sur votre compte MADIL
  • Bénéficier de bonus sur les recharges (selon les promotions en cours)
  • Passer des commandes rapidement sans ressaisir vos informations de paiement
  • Suivre plus facilement vos dépenses

Les fonds déposés sur votre compte n'expirent pas et peuvent être utilisés à tout moment.

Puis-je obtenir une facture pour mes commandes ?

Oui, vous pouvez obtenir une facture pour toutes vos commandes :

  1. Connectez-vous à votre compte
  2. Accédez à la section "Historique des commandes"
  3. Cliquez sur la commande pour laquelle vous souhaitez une facture
  4. Téléchargez la facture au format PDF

Si vous avez besoin d'une facture personnalisée (avec vos coordonnées professionnelles), contactez notre service comptabilité.

Que faire en cas de problème de paiement ?

En cas de problème de paiement :

  • Vérifiez que votre carte est valide et dispose de fonds suffisants
  • Assurez-vous que les informations de paiement sont correctes
  • Contactez votre banque pour vérifier d'éventuelles restrictions
  • Essayez un autre mode de paiement

Si le problème persiste, contactez notre support technique avec les détails de l'erreur.

Compte et Profil

Comment créer un compte sur MADIL ?

Pour créer un compte MADIL :

  1. Rendez-vous sur notre page d'inscription
  2. Remplissez le formulaire avec votre email et un mot de passe sécurisé
  3. Confirmez votre adresse email via le lien envoyé
  4. Complétez votre profil avec vos informations personnelles
  5. Votre compte est maintenant actif et prêt à utiliser

L'inscription est gratuite et sans engagement.

Que faire si j'ai oublié mon mot de passe ?

Si vous avez oublié votre mot de passe :

  1. Cliquez sur "Mot de passe oublié" sur la page de connexion
  2. Entrez l'adresse email associée à votre compte
  3. Cliquez sur le lien de réinitialisation envoyé par email
  4. Créez un nouveau mot de passe sécurisé

Si vous ne recevez pas l'email de réinitialisation, vérifiez vos spams ou contactez notre support.

Comment modifier mes informations personnelles ?

Pour modifier vos informations personnelles :

  1. Connectez-vous à votre compte
  2. Accédez à la section "Mon profil"
  3. Modifiez les informations souhaitées (nom, email, photo, etc.)
  4. Cliquez sur "Enregistrer les modifications"

Certaines modifications (comme l'adresse email) peuvent nécessiter une confirmation.

Comment supprimer mon compte MADIL ?

Pour supprimer votre compte :

  1. Connectez-vous à votre compte
  2. Accédez aux "Paramètres du compte"
  3. Cliquez sur "Supprimer le compte" en bas de page
  4. Confirmez votre choix en entrant votre mot de passe

Attention : La suppression de compte est irréversible. Toutes vos données, commandes et soldes seront définitivement supprimés.

Problèmes Techniques

Le site ne se charge pas correctement, que faire ?

Si le site ne se charge pas correctement :

  • Videz le cache de votre navigateur et rechargez la page
  • Essayez un autre navigateur (Chrome, Firefox, Safari, Edge)
  • Vérifiez votre connexion Internet
  • Désactivez les extensions qui pourraient interférer
  • Mettez à jour votre navigateur vers la dernière version

Si le problème persiste, contactez notre support technique.

Je ne reçois pas les emails de confirmation, que faire ?

Si vous ne recevez pas nos emails :

  • Vérifiez votre dossier de courrier indésirable/spam
  • Ajoutez noreply@madil.com à votre liste de contacts
  • Vérifiez que vous avez saisi la bonne adresse email
  • Vérifiez l'espace de stockage de votre boîte email
  • Contactez votre fournisseur d'email pour vérifier d'éventuels filtres

Vous pouvez également demander un nouvel envoi depuis votre compte.

La commande échoue systématiquement, quelle est la cause ?

Plusieurs raisons peuvent causer l'échec d'une commande :

  • Lien incorrect : Vérifiez que le lien est valide et accessible
  • Compte privé : Certains services nécessitent un compte public
  • Limites de la plateforme : Certains comptes peuvent avoir des restrictions
  • Problème technique temporaire : Réessayez après quelques minutes
  • Solde insuffisant : Vérifiez que vous avez assez de crédit

Si le problème persiste, contactez notre support avec le numéro de commande.

Comment signaler un bug ou un problème technique ?

Pour signaler un bug ou problème technique :

  1. Notez précisément les étapes pour reproduire le problème
  2. Capturez une screenshot si possible
  3. Notez votre navigateur, version et système d'exploitation
  4. Contactez notre support technique avec ces informations

Notre équipe technique investiguera et vous tiendra informé de la résolution.
